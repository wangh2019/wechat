# Life9 / 九格

副标题：个人预算与生活资源规划

Life9 / 九格是一个微信原生小程序，用来做个人预算分配、生活目标管理和本月支出记录。V0.0.1 只包含本地初始设置、8+1 预算仪表盘、记一笔、记录列表和我的页面。

本项目不是投资顾问、证券推荐工具、金融交易工具或 AI 理财工具，不包含收益预测、微信登录、支付、CloudBase、服务器或第三方 API。

## 安装

不需要 `npm install`。

仓库使用微信原生小程序和 TypeScript，首版没有第三方依赖。微信开发者工具会处理小程序 TypeScript 编译。

## 在微信开发者工具中导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库根目录：`D:\study\software\AI CODE\WeChat`。
4. AppID 可以先使用微信开发者工具提供的测试号，也可以填写你自己的正式小程序 AppID。
5. 导入后确认小程序目录为 `miniprogram/`。
6. 点击“编译”，首页会先进入初始设置。

## 使用测试 AppID 或自己的 AppID

当前 `project.config.json` 已写入 AppID：`wx28f3cd419286312e`。

如果只做本地测试，也可以在微信开发者工具中改用测试号。上传代码时必须使用正式小程序 AppID，并确保当前微信开发者账号拥有该小程序的开发者权限。

## 真机预览

1. 在微信开发者工具中点击“预览”。
2. 使用绑定开发者身份的微信扫码。
3. 在手机上完成初始设置，测试记账、删除记录、修改预算模式和关闭重开后的本地数据保留。

## 上传代码

1. 在微信开发者工具中确认 AppID 是正式小程序 AppID。
2. 点击右上角“上传”。
3. 版本号建议填写 `0.0.1`。
4. 项目备注可填写：`Life9 V0.0.1 publishable local budget MVP`。
5. 上传成功后，进入微信公众平台。
6. 路径：微信公众平台后台 -> 版本管理 -> 开发版本。
7. 选择刚上传的开发版本，提交审核。

## 本地测试

如果机器安装了 Node.js，可运行：

```bash
node tests/business.test.js
```

测试覆盖 4 个预算 preset 合计 100%、金额格式化、收入预算计算、交易汇总和删除交易后的金额恢复。
